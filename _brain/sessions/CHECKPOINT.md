# Session Checkpoint

Use approximately hourly, or after a major decision or task change.

- Is the current context still focused and current?
- Have major decisions been recorded?
- Has the task changed?
- Would a handoff make continuation safer?

Choose one: continue, generate handoff, compact current session, or start a fresh session.

Health guide: **GREEN** = focused; **YELLOW** = multiple tasks or substantial context; **RED** = write a handoff and continue fresh. Use duration, loaded files, task changes, decisions, and historical context as signals; do not invent token counts.
