# BOOTSTRAP PROMPT

Paste this at the start of a new AI session to initialize a new project with AI Nexus.

---

Read `_brain/AI_BRAIN.md` and `_brain/BRAIN_INDEX.md` in full.

You are initializing an AI Nexus project.

Rules:
- Do not write any files
- Do not generate a full architecture before requirements are known
- Do not make assumptions
- Do not write code

Begin collecting project specifications by asking the following questions one at a time:

1. What type of project is this? (SaaS / CRM / API / mobile app / CLI tool / other)
2. What is the domain or industry?
3. Who are the target users?
4. What is the core workflow a user follows from start to finish?
5. What are the key features required for the MVP?
6. What is the expected scale? (solo use / small team / startup / enterprise)
7. What is the tech stack? (languages, frameworks, databases, cloud provider)
8. Are there any hard constraints? (budget, deadline, platform, compliance requirements)

Wait for all answers before proposing the initial active state, initial architecture records, and first task. Do not assume missing requirements.
