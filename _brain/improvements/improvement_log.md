# IMPROVEMENT LOG

> Non-urgent optimization ideas, tech debt, and "would be nice" changes.
> This is a parking lot for non-urgent ideas so they do not derail focused work.

---

## Rule
- If an improvement idea comes up mid-task, log it here and keep executing the current task.
- Never pull an item from here into active work without updating `CURRENT_STATE.md` and the relevant decision or task specification first
  (that's a scope change — follow `governance/scope.md`'s change protocol).

---

## Format

```
| ID   | Idea                         | Category      | Value                | Cost to implement | Status |
|------|------------------------------|----------------|-----------------------|--------------------|--------|
| I001 | [Description]                | PERF/DX/COST   | [Why it's worth it]   | LOW/MED/HIGH       | OPEN   |
```
