## Context policy

If a global brain is configured, load it only after the local context selector identifies a task-specific need. Load only the relevant compact summary or source; never scan the global repository.

Suggested summaries:

1. `summaries/skills-summary.json` — approach selection
2. `summaries/bugs-summary.json` — bug-fix work
3. `summaries/projects-summary.json` — retrospectives or prior-project lookup
4. `summaries/references-summary.json` — standards/specification citations
